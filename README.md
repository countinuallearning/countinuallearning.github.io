# Shashitu Assaye — QA Portfolio Website
A responsive dark navy/blue QA portfolio website.

## Before publishing
1. Open `index.html` and replace `YOUR_EMAIL@example.com` with your professional email.
2. Review every project description and remove or adjust anything you cannot publicly disclose.
3. Optional: add your CV PDF in this folder and create a CV download link.

## Publish with GitHub Pages
1. Create/sign in to GitHub and create a **public** repository named `shashitu-assaye.github.io`.
2. Upload `index.html` (and any assets) to the repository root.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for deployment. Your website address should be `https://shashitu-assaye.github.io/`.

Keep confidential client data, internal screenshots, credentials, customer data, and private project details out of a public portfolio.
